# FE-04 업체 설정

## Direction contract

THESIS: 바쁜 사장님이 설정 하나를 찾아 수정하고 저장 여부를 즉시 확인한다. 긴 설정을 한 화면에 모아 한꺼번에 저장하는 방식을 피한다.

OWN-WORLD: 기존 흰 바탕·주황 주요 동작·Noto Sans KR·52px 입력창·평면 구분선·10~12px 모서리를 유지한다.

STORY: 업체정보·방문지역·영업시간·작업시간·접수/예약 중 하나를 고르고 수정·저장·취소한다. 다른 항목의 미저장 입력은 보존한다.

FIRST VIEWPORT: 업체명 아래 다섯 설정 행을 배치한다. 각 행은 설정명과 짧은 현재 상태를 담는다. 편집 화면은 제목·입력·저장 상태·하단 저장/취소 순서다.

FORM: 피그마 B11(2030:212)·B12(2030:260)의 좁게 지정된 기존 화면 확장이다. 사용자가 기존 스타일·항목별 저장을 승인했다. 새 콘셉트 선정/seed는 적용하지 않는다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

기존 일로 사장님 UI를 확장한다. 흰 바탕, 주황색 주요 동작, Noto Sans KR, 52px 입력창, 항목별 저장을 유지한다. 피그마 B11(2030:212)·B12(2030:260)를 기준으로 긴 설정을 업체정보·방문지역·영업시간·작업시간·접수/예약으로 나눈다. 사용자는 2026-11-02 이 구성을 승인했다.

바쁜 사장님이 설정 하나를 찾아 수정하고 저장 여부를 바로 확인하는 것이 목표다. 미저장 입력은 다른 항목을 열어도 유지하고, 취소는 해당 항목만 되돌린다. 기존 상담·예약 정책은 변경하지 않는다.

FE-04는 화면·입력 검증이다. FE-07은 실제 인증·설정 API 연결이다. 백엔드 PR #21의 DTO로 호출 모듈을 준비하되, 병합·배포·문자 인증 실증과 주소/행정지역 검색 연결은 별도로 검증한다. 미리보기는 명시적인 서버 환경변수로만 열고, 예시 정보는 메모리에만 저장한다. 운영 경로는 가짜 인증을 허용하지 않는다.

## 검증 기준

- 업체정보·방문지역·요일별 영업시간·휴무·점심·작업시간·예약 한도·여유시간 입력
- 서비스 제공 여부와 자동 예약 허용 여부 분리
- 자동 예약 OFF와 신규 접수 중지 분리, 기존 예약/대화 유지 안내
- 누락/시간 역전/음수/중복 지역 차단, 실패 시 입력 보존, 항목별 저장/취소
- 320~430px 모바일, 키보드 접근, 오류/저장 상태 안내, 운영 경로 인증 차단
