# FE-07 사장님 로그인 서버 연동

문자 인증 요청·확인 → 사장님 홈 → 내 계정 조회 → 서버 로그아웃을 연결합니다. 실제 세션은 서버 만료 시각을 따르며 같은 브라우저 탭에서 유지합니다. 화면 검수용 로그인은 `OWNER_AUTH_PREVIEW_ENABLED=true`인 환경에서만 사용합니다.

개발 서버의 승인된 테스트 계정으로 실제 SMS 수신, 로그인, 업체명·마스킹된 번호 조회, 로그아웃 안내를 확인했습니다. 업체 문의 링크·고객 접수·예약은 이 PR 범위가 아닙니다.

로컬 브라우저 회귀 검사: `NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:35116`으로 프론트를 `http://127.0.0.1:35115`에서 실행하고 `node tests/owner-auth-live.browser.mjs`를 실행합니다. Playwright가 테스트 응답을 반환하므로 실제 서버나 문자 서비스는 사용하지 않습니다.
