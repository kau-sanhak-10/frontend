백엔드 [PR #37](https://github.com/kau-sanhak-10/backend/pull/37)은 방문 가능시간 조회 구현이 있으며 11/14 확인 시 open이다. DS-04와 같은 응답을 사용한다. 이 PR에 추가된 `OWNER_HANDLING`도 사장님 확인 안내로 처리한다. 예약 최종 확정은 이 PR의 범위가 아니다. MapClient의 local/dev 값은 가짜 지도이므로 실제 이동시간 검증은 BE-10/15에서 구분한다.

## 실행 경로와 안전 경계

- `/owner/settings`: 실제 `own_` 세션으로 BE-03 API 호출. 예시 세션은 실제 설정을 읽지 않는다.
- `/customer/{linkToken}`: 기존 `CUSTOMER_LIVE_ENABLED=true` 기준. 방문 시연 지정 링크는 기존 동작을 유지한다.
- `CUSTOMER_PHOTO_ENABLED=true`: 일반 업체 링크의 사진 동의·업로드를 여는 별도 서버 설정. 기존 `CUSTOMER_PHOTO_DEMO_ENABLED`는 지정 시연 링크용으로 유지한다. 기본은 비활성이다.
- 사진 취소는 기존 결정대로 비활성 유지한다.
- `/customer/booking-preview?scene=...`: `CUSTOMER_PREVIEW_ENABLED=true`일 때만 열리는 화면 예시. 실제 예약·문자·외부 API를 호출하지 않는다.
- `normal`, `unverified`, `empty`, `load-error`, `owner`, `safety`, `expired`, `conflict`, `network`, `notification`, `existing` 예시를 지원한다.
- `customer-booking-api.ts`는 명세의 후보 조회·최종 확정 호출 모듈이다. UI 프리뷰는 이 모듈을 호출하지 않는다. 운영 연결은 FE-14에서 담당한다. 후보·확정 응답을 검사하고 문의 토큰은 헤더로만 전달한다.
- 고객 토큰은 URL/영구 저장소에 남기지 않는다. 브라우저에서 서버의 접근 통제·문자 인증을 대체하지 않는다.

## 검증

선언된 잠금 파일 그대로 별도 로컬 의존성을 설치해 Next 16.4.5에서 확인했다. 원래 작업 폴더의 공유 node_modules는 바꾸지 않았다.

```powershell
npm run check
npm run build -- --webpack
```

단위 테스트 106개, 포맷·lint·타입 검사·운영용 빌드 통과. 개발 환경의 외부 node_modules 연결 때문에 webpack을 사용하며 배포 설정은 바꾸지 않았다.

다음 브라우저 검사는 운영용 로컬 실행본 + 모의 서버 응답에서 통과했다. 공유 Dev의 실제 저장/문자 발송을 뜻하지 않는다.

```powershell
# 로컬 실행본은 NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:35116으로 빌드
# 실행 시 CUSTOMER_LIVE_ENABLED=true, CUSTOMER_PREVIEW_ENABLED=true
# 테스트 서버 포트 35115, API 응답은 각 테스트의 브라우저 격리 모의 응답
$env:PLAYWRIGHT_MODULE_PATH = '설치된 playwright/index.mjs 절대 경로'
$env:PLAYWRIGHT_CHANNEL = 'chrome'
node tests/customer-booking.browser.mjs
node tests/customer-visit.browser.mjs
node tests/owner-auth-live.browser.mjs
```

## 기존 화면과의 디자인 연속성

PRODUCT.md·고객 상담/예약·업체 설정 화면 기준과 구현, 로컬 390px 예약·방문정보·설정 증빙을 대조했다. 예약은 기존 intake의 화면 틀·입력·하단 동작·확인 목록을 재사용한다. 흰 바탕·주황 주요 동작(`#ff9200`), 최대 430px 화면 폭, 52px 입력/주요 버튼, 10px 입력 모서리와 평면 구분을 유지한다. 시간 선택은 같은 계열의 64px 라디오 영역으로 확장했다. 전역 글꼴 선언은 `Noto Sans KR → Malgun Gothic → system-ui → sans-serif`이며, Noto Sans KR을 새로 내려받거나 포함하지 않았다.

새 이미지 자산은 없고 예약의 뒤로가기 아이콘은 기존 `/customer/back.svg`를 재사용한다. 이는 기존 화면의 기능 확장 확인이며 새 시각 정체성이나 전역 디자인 정책을 정한 것이 아니다. 기존에 없는 DESIGN.md·`.impeccable/design.json`은 생성하지 않았다. PRODUCT.md의 플랫폼 표기(`web (모바일 우선, 사장님 PWA)`) 인식 경고도 기존 문서 상태로 남겼다.

이 확인은 코드와 로컬 모의 응답 화면의 연속성에 한한다. 위 검증 결과를 공유 Dev 저장·실제 문자 인증·주소 검색·운영 예약 통합 완료로 해석하지 않는다.
